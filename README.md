# 🚗 Smart Parking Management System

A smart parking system built using **C++ (backend)** and a **web-based dashboard (HTML, CSS, JS)** that visualizes parking slots in real time.

---

## 🌐 Live Demo
👉https://advaitchitale31.github.io/smart-parking-systems/

---

## 📌 Features

- 🧠 Smart slot allocation (distance-based + scoring)
- 🚗 Vehicle entry and exit management
- 💰 Automatic parking fee calculation
- 🔍 Search vehicle by number
- 📊 Real-time dashboard visualization
- 🔄 Live data sync using file handling
- 🎯 VIP priority support

---

## 🧠 How It Works

- The **C++ backend**:
  - Assigns optimal parking slots
  - Tracks entry time
  - Calculates parking fees
  - Updates parking data in `data.txt`

- The **Web Dashboard**:
  - Reads `data.txt`
  - Displays slot status (Free / Occupied)
  - Shows live stats (Total, Occupied, Free)

## ⚙️ Tech Stack

- 💻 C++
- 🌐 HTML, CSS, JavaScript
- 📁 File Handling (for backend-frontend sync)
